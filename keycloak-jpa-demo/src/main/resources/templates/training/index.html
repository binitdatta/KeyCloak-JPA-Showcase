YOUTUBE TRAINING SERIES

Keycloak Client Auth & Spring Data JPA

Nine self-contained episodes. Each page below is written as a recording script: goal, prerequisites, on-screen steps, and a wrap-up talking point.

A. Signed JWT client auth

Client authenticates to Keycloak with a self-signed JWT assertion instead of a shared secret.
B. X509 Certificate client auth

mTLS-style client authentication using a client certificate.
C. Signed JWT with Client Secret

HMAC-signed JWT assertion using the client secret as the signing key.
D. Capability Config

Authorization Services and the Device Authorization Grant, tested end-to-end.
E. OIDC CIBA Grant

Client-initiated backchannel auth, and why it needs an Authentication Channel Provider Keycloak doesn't ship by default.
F1. Custom Client Authenticator

Build and register a ClientAuthenticatorFactory SPI provider.
F2. First Broker Login

Extend Create-User-If-Unique to call this app's REST API as an external identity source.
F3. Post-Login Flow

A post-login authenticator that provisions realm roles and groups right after broker login.
G. JPA Relationships

1:1, 1:many, and many:many over the ecommerce schema, annotation by annotation.
