EPISODE A · PRIVATE_KEY_JWT · CLIENT AUTHENTICATION

Signed JWTNo shared secret. The client signs its own proof.

A normal confidential client authenticates with a shared secret sent on every request. private_key_jwt removes that entirely: the client signs a JWT with a private key only it holds, and Keycloak verifies the signature against a public certificate it was given in advance. The private key never crosses the network — not at setup time, not at request time.

Try it live

Signs a client assertion server-side with the private key on file for signed-jwt-client, trades it for a real access token at Keycloak's token endpoint, then calls userinfo with that token — against your actual local Keycloak, not a mock.
