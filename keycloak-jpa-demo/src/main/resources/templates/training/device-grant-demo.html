EPISODE D · DEVICE AUTHORIZATION GRANT · RFC 8628

Device Grant — Live DemoThe TV shows a code. The human approves on their phone.

This page plays an input-constrained device (a TV, a CLI, a kiosk). It asks Keycloak for a device code and a short user code, displays the user code, and polls the token endpoint. You play the human: log in as alice in the second window and approve. No password is ever typed into the device.

Try it live

Runs against your actual local Keycloak, not a mock.

The approval window opens on Keycloak's verification page. Allow popups for this site if it is blocked. The verification URL is whatever Keycloak advertises (your realm's Frontend URL), so it may be on :8443.
